# Наші Гроші 💰

Мобільний додаток (Android / iOS) для обліку сімейного бюджету. Розроблено на базі **React Native** та **Expo**.

## ✨ Основні можливості

- **Облік операцій**: швидке додавання, редагування та видалення доходів і витрат.
- **Хто вносить**: поділ витрат між членами сім'ї («Андрій» та «Людмила») або спільний огляд.
- **Дворівневі категорії**: гнучка категоризація витрат та доходів із можливістю додавання власних підкатегорій та іконок.
- **Дашборд-хаб на головному екрані**:
  - **Плашка Балансу** (активний портал в Аналітику): відображення поточного балансу з інтерактивною **SVG-хвилею тренду** (динаміка за місяць) та підсумками доходів/витрат.
  - **Плашка Бюджету** (активний портал у Бюджет): кільцева діаграма (**Donut Chart** на SVG) з контролем ліміту, прогрес-баром і залишком коштів.
- **Двоступеневий плавний скрол**: плашки займають 40% висоти при відкритті, а при скролі списку транзакцій плавно згортаються (через `Animated.event` з нативним драйвером 60/120 fps без мерехтіння), даючи операціям 100% площі екрану.
- **Планування Бюджету**:
  - Спільний та особистий режими бюджету.
  - Встановлення лімітів по окремих категоріях.
  - Можливість копіювання витрат минулого місяця в один клік.
- **Аналітика та статистика**:
  - Річний баланс, сукупні доходи та витрати.
  - Розподіл витрат за категоріями та джерелами доходів.
- **Безпека**: захист входу за допомогою біометрії (Fingerprint / Face ID).
- **Синхронізація**: збереження в Firestore (Firebase) для спільного доступу між смартфонами.
- **Теми оформлення**: автоматична (системна), темна (OLED) та світла.

## 📁 Структура проєкту

```
.
├── App.js                         # Головний компонент, стан, синхронізація та навігація
├── app.json                       # Конфігурація Expo
├── package.json                   # Залежності та скрипти збірки
├── babel.config.js                # Налаштування Babel для Expo
├── .env.example                   # Шаблон конфігурації Firebase
├── src/
│   ├── screens/
│   │   ├── CurrentMonthScreen.js  # Головний екран: дашборд-хаб (40%), SVG тренд, Donut chart, список операцій
│   │   ├── AnalyticsScreen.js     # Екран річної аналітики та статистики
│   │   └── BudgetScreen.js        # Екран налаштування та контролю лімітів бюджету
│   ├── theme/
│   │   └── theme.js               # Світла та темна теми
│   ├── constants.js               # Категорії, джерела доходів, назви місяців
│   └── services/
│       └── firebase.js            # Ініціалізація Firebase / Firestore
└── CONTEXT.md                     # Опис контексту та архітектури
```

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/android1303/nashi-hroshi-updates.git
cd nashi-hroshi-updates
```

### 2. Встановлення залежностей
```bash
npm install
```

*(Якщо виникає потреба доставити SVG підтримку: `npx expo install react-native-svg`)*

### 3. Налаштування змінних оточення (опціонально)
Створіть файл `.env` на основі `.env.example` та вкажіть параметри вашого Firebase проєкту:
```bash
cp .env.example .env
```

### 4. Запуск у режимі розробки
```bash
npx expo start -c
```
Відскануйте QR-код за допомогою додатку **Expo Go** на вашому Android або iOS смартфоні.
