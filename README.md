# Наші Гроші 💰 (v1.0.5 — з ШІ-Асистентом)

Мобільний додаток (Android / iOS) для обліку сімейного бюджету з хмарною синхронізацією **Firebase Firestore** та вбудованим мультимодальним **ШІ-Асистентом (Google Gemini)**. Розроблено на базі **React Native** та **Expo SDK 51**.

---

## ✨ Основні можливості

### 🤖 ШІ-Асистент витрат (нове у `v1.0.5`)
- **🎙 Голосове додавання витрат і доходів**: скажіть однією фразою кілька операцій (наприклад: *«Заправив авто на 1200 грн на ОККО і купив каву за 85 грн»*), і ШІ автоматично розділить їх на окремі транзакції, визначить суми, категорії, підкатегорії та коментарі.
- **📷 Сканування чеків та скріншотів банку**:
  - **🧾 Загальною сумою**: фотографуйте чек із супермаркету чи завантажуйте скріншот із Monobank / Приват24 — ШІ витягне підсумкову суму та назву закладу.
  - **🛒 По позиціях / категоріях**: ШІ автоматично розіб'є один довгий чек на окремі категорії витрат.
- **💬 Текстовий смарт-ввід**: швидкий розбір списку витрат, написаних у довільній формі.
- **🔑 Спільний сімейний ключ Gemini API**: вводиться один раз у додатку і автоматично синхронізується через Firebase між обома смартфонами.

### 📊 Дашборд-хаб та інтерфейс
- **Плашка Балансу (активний портал в Аналітику)**: відображення поточного балансу з інтерактивною **SVG-хвилею тренду** (Bezier curve з градієнтом) та підсумками доходів/витрат.
- **Плашка Бюджету (активний портал у Бюджет)**: кільцева діаграма (**SVG Donut Chart**) з контролем ліміту, прогрес-баром і залишком коштів.
- **Двоступеневий плавний скрол (60/120 fps)**: плашки займають 40% висоти екрану при відкритті, а під час скролу списку операцій плавно згортаються через нативний драйвер `Animated.event`.
- **Хто вносить**: поділ витрат між членами сім'ї («Андрій» та «Людмила») або спільний огляд («Усі»).
- **Планування Бюджету**: спільний та особистий режими, ліміти по підкатегоріях, копіювання витрат минулого місяця в один клік.
- **Безпека та теми**: біометрія (Fingerprint / Face ID), приховування балансу (`••••`), темна OLED та світла теми.

## 🧠 Економія токенів: система «Архітектор → Молодша модель»

У проєкті налаштовано двоступеневий конвеєр для економії токенів:
1. **Індексна карта ([`CONTEXT.md`](file:///home/antigravity/android1303/nashi-hroshi-updates/CONTEXT.md))**: містить точні шляхи та діапазони рядків кожного модуля, щоб старша модель (Claude / Argon / Pro) не читала весь код проєкту.
2. **Скрипт-маршрутизатор ([`scripts/architect-router.js`](file:///home/antigravity/android1303/nashi-hroshi-updates/scripts/architect-router.js))**:
   ```bash
   node scripts/architect-router.js "Додати фільтр пошуку операцій за коментарем"
   ```
   Скрипт автоматично:
   - визначає, які частини робить **Старша модель (Архітектор)**, а які — **Молодша модель (Flash / Haiku / Mini)**;
   - вирізає **тільки потрібні рядки коду** з релевантних файлів (економія 80–90% токенів контексту);
   - генерує готовий точний промпт-ТЗ для молодшої моделі.
3. **Оновлення єдиного файлу проєкту ([`PROJECT_FULL_CODE.md`](file:///home/antigravity/android1303/nashi-hroshi-updates/PROJECT_FULL_CODE.md))**:
   ```bash
   node scripts/sync-project-doc.js
   ```
