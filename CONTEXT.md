# Контекст проєкту «Наші Гроші»

## Що це
Мобільний додаток (Android) для обліку сімейного бюджету. Ним користуються двоє членів родини
(у коді зашиті «Андрій» і «Людмила» як джерела, тобто «Хто вносить»).

## Що є в цьому репозиторії
**Це НЕ вихідний код.** Репозиторій `nashi-hroshi-updates` слугує каналом оновлень:

| Файл | Призначення |
|------|-------------|
| `index.android.bundle` | Зібраний (мініфікований) JS-бандл Expo / React Native |
| `metadata.json` | Метадані експорту Expo (`expo export`), посилається на `.hbc`-файл, якого тут немає |
| `version.json` | Маніфест версії (`versionCode`, `versionName`, `apkUrl`, `changelog`) |

Вихідний код зберігається окремо (поза цим репозиторієм).

## Стек (за вмістом бандла)
- Expo + React Native, бандлер Metro
- Дані: `@react-native-async-storage/async-storage`, ключі: `transactions`, `categories`, `sources`,
  `appTheme`, `biometricsEnabled`, `notificationsEnabled`
- `expo-local-authentication` (вхід через біометрію), `expo-notifications` (нагадування),
  `expo-file-system` (завантаження оновлень)

## Функції
- Операції «Витрата» / «Дохід»: сума, категорія, коментар, дата, хто вносить
- Категорії за замовчуванням (Продукти, Сільпо, Кафе, Пальне, Комуналка, Ліки, Зарплата, Фріланс…) і власні категорії
- Головна, Аналітика (огляд по місяцях і роках, річний баланс), пошук операцій
- Теми: Світла / OLED Чорна / Авто; захист біометрією; щоденне нагадування

## Механізм оновлень
1. Додаток завантажує `version.json` з `raw.githubusercontent.com/.../main/`.
2. Якщо `versionCode` більший за вбудований, пропонує завантажити `index.android.bundle`.
3. Бандл зберігається в `documentDirectory`, після чого додаток закривається.
